# Security Policy

## Responsible Use

This repository is intended for educational purposes and for recovering your own MultiBit Classic / BitcoinJ wallet files only.

Do not use these tools or instructions to access wallets, keys, or funds that do not belong to you.

## Protect Your Wallet Data

Never upload, commit, paste, or share any of the following:

- `.wallet` files
- private keys
- seed phrases
- wallet passwords
- recovered key output
- screenshots showing wallet data
- logs or terminal output containing private information

Run recovery tools locally and offline whenever possible.

## Reporting Security Issues

If you find a security issue in this repository, please do not open a public issue containing sensitive details.

Instead, report the issue privately using GitHub Security Advisories:

1. Go to this repository on GitHub.
2. Select **Security and quality**.
3. Select **Advisories**.
4. Choose **Report a vulnerability** or contact the repository owner privately.

## Scope

This project is provided as-is for legacy wallet recovery research and personal recovery use.

No guarantee is made that the tools are complete, safe for every wallet file, or compatible with every system.
